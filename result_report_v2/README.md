# FcRH5 D9 特异性VHH表位精修报告 v2

完成时间：2026-09-01 15:26:37（Asia/Shanghai）

## 本版做了什么

1. 将用户提供的专利分析报告作为证据输入，提取D9依赖性、FcRH2/FcRH3交叉反应和抗体成熟造成选择性损失等约束。
2. 对FcRH5 D9全部表面残基计算可达面积和三维邻接关系。
3. 将候选位点映射至FcRH5 D1–D8及FcRH1/2/3/4/6各Ig样域，寻找不能被其他域完整复现的组合表面。
4. 形成用于VHH筛选的首选表位、探索性备选表位、负筛顺序和突变验证方案。
5. 以本地高可信FYT-499–D9 AF3模型的正常VHH骨架为几何标尺，完成刚性覆盖搜索和碰撞评估。
6. 直接复核专利Fig.10、Fig.24及Fig.25，确定“弱D3结合”只对应FcRH3/FCRL3；专利未报告FcRH5自身D3弱结合。
7. 将VHH覆盖图改为不被D9遮挡的侧向界面视图，并加入平移16 Å的open-book解释图；两种视图都保存在同一PSE场景中。
8. 根据本项目表位尺寸和公开VHH结构/人工库数据，给出CDR1/2保留策略及CDR3 12–15 aa主库、9–11 aa短对照、16–18 aa延伸探索的分层建议。

## 最重要结论

首选表位A不是一段连续短肽，而是空间连续的组合脊面。特异性信息集合仍为 **L781/R785/D822/R829/T832**，但一个正常VHH的推荐必需能量核心应收缩为 **L781/R785/D822/R829**；**T832作为可选边缘位点**。四残基核心最大Cα跨度16.55 Å，可由正常VHH覆盖；五残基集合跨度23.65 Å，属于边缘可行；17残基完整支撑面不应要求全部覆盖。

旧版蓝/紫区域应降级为“预测接触参考”，不再作为单独的高特异性VHH表位。专利与新候选总体相符，但专利没有残基级数据，故不能声称已实验确证。

专利术语已经复核：**约90 nM弱结合对象是FcRH3/FCRL3旁系受体**。FcRH5自身D3没有被专利作为弱结合对象测试或报告；它只保留为本项目的计算型内部负筛域。

## 如何阅读

- 先打开 `report.html` 查看完整图文结论。
- 用PyMOL打开 `structures/01_primary_D9_specificity_design.pse` 查看D9表位；切换scene观察核心、完整足迹、化学性质及旧表位对照。
- 打开 `structures/02_all_domains_comparison.pse`，逐一启用对象比较D8与FcRH3等高风险域。
- 打开 `structures/03_VHH_rigid_coverage_feasibility.pse` 查看正常VHH骨架对四残基紧凑核心的覆盖姿态；这是未松弛的几何可行性模型，不是亲和力预测。
- 在该PSE中，`01_side_interface`为真实贴合侧视图，`02_open_book_interface`为仅用于展示接触面的16 Å平移图，`03_core_labels`显示残基标签。
- `tables/08_VHH_CDR_length_recommendations.csv`给出可直接用于建库或生成模型分组的CDR长度建议。
- 表格02中 `full_core_reproduced=NO` 说明该域无法完整复现候选核心，但不等于绝对不会交叉结合。

## 证据边界

这是结构与序列联合优选结果，不是实验确证表位。最关键的下一步是D9单点/组合突变、反向移植、D7/D8与FcRH1/2/3/4/6负筛以及全长细胞FACS验证。
