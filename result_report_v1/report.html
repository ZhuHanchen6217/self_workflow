VHH设计与筛选建议

蓝表位路线

  1. 正筛使用完整折叠D9或全长ECD，不使用TAEHS短肽。
  2. 促使长CDR3跨到R796/L805邻近表面。
  3. 强制反筛FcRH5 D7、FcRH2 Ig4、FcRH3 Ig5。
  4. 用FcRH5 D5判断序列依赖还是构象依赖。

紫表位路线

  1. 让VHH同时依赖R796与L805。
  2. 利用R796电荷和L805/F体积差异。
  3. 尽量覆盖A811以继续排除FcRH1/D8/FcRH3 Ig6。
  4. 确认N806潜在糖基化对结合的影响。
优先级：紫表位VHH优先；蓝表位只有在足迹跨出TAEHS时才适合追求FcRH5家族特异性。

限制与下一步

  1. 扩展表位是图像约束预测，尚未经过逐残基实验扫描。
  2. PSE中的抗体姿态允许少量原子冲突，仅用于定位表位方向。
  3. AlphaFold表面是预测构象，天然糖基化和膜环境可能改变局部可及性。
  4. 建议下一步用R796S、L805F、A811T/E、E812A和S814A进行突变验证，并同时开展FcRH2/3及FcRH5 D7反筛。
